# Issue tracker: GitHub

Issues and PRDs for this repo live as GitHub issues. Use the `gh` CLI for all operations and infer the repository from the configured Git remote.

## Conventions

- Create specs and work items as GitHub issues.
- Read issues with their comments and labels before acting on them.
- Apply and remove triage labels through GitHub Issues.
- Pull requests are not a request or triage surface.
- When an engineering skill says to publish to the issue tracker, create a GitHub issue.
